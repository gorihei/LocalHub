# Local Hub 仕様

この文書は、利用者から見える動作と実装が満たすべき契約を記録する。
システム構成の現状は`ARCHITECTURE.md`、設計判断と背景は`adr/`、変更単位の履歴は
`CHANGELOG.md`を参照する。

## プラグイン

### 実行と通信

- プラグインのサイドカー実行ファイルはLocal Hubの子プロセスとして起動する。
- コアとサイドカーは、標準入力・標準出力上の改行区切りJSON-RPCで通信する。
- 標準エラー出力はコアが収集し、プラグインログとして表示する。
- Windowsでは、コンソール型サイドカーであっても独立したコンソールウィンドウを
  表示しない。ウィンドウを表示しない場合も、標準入出力のパイプは維持する。
- サイドカーの終了はコアが監視し、意図しない終了はクラッシュとして扱う。

### 障害分離

- プラグインはコアプロセスから分離し、プラグインの障害でLocal Hub本体を終了させない。
- 短時間の連続クラッシュを検出したプラグインは自動的に無効化する。

## グローバルショートカット

- ウィンドウの表示・非表示を切り替えるグローバルショートカットを設定できる。
- キー割り当ては文字列を手入力せず、設定欄にフォーカスして実際のキーの組み合わせを
  押すことで指定する。
- 修飾キーを押すと記録中の組み合わせを表示するが、修飾キーだけでは割り当てを確定しない。
  記録中に`Esc`を単独で押すと変更を取り消す。
- 検出した割り当ては「適用」を押した時点で登録・保存する。登録できない組み合わせや
  他アプリと競合する組み合わせはエラーを表示する。

## 開発者ツール

- 複数行の入力欄と結果欄には共通のコードエディタを使用する。JSON、YAML、XML、
  Markdown、SQLは言語に応じて構文を色分けし、その他はプレーンテキストとして表示する。
- 編集可能なエディタでTabキーを押すと、現在の選択範囲またはカーソル位置へ
  タブ文字を挿入する。

### SQL整形

- SQLは端末内で整形し、入力内容を外部へ送信しない。
- 標準SQL、MySQL、MariaDB、PostgreSQL、SQLite、SQL Server、Oracle PL/SQL、
  BigQuery、Snowflakeの方言を選択できる。
- キーワードの大文字・小文字・入力維持と、2または4スペースのインデントを選択できる。
- 入力欄と結果欄では、選択した方言に応じてSQL構文を色分けして表示する。
- 整形に失敗した場合はエラーを表示し、結果をクリアする。

### QRコード生成

- 任意のテキストまたはURLからQRコードを端末内で生成し、入力内容を外部へ送信しない。
- 誤り訂正レベルはL、M、Q、Hから選択できる。
- 出力PNGサイズは256、512、1024ピクセルから選択できる。
- 生成結果を画面上で確認し、PNGファイルとして任意の場所へ保存できる。

### 正規表現テスト

- 正規表現、フラグ、対象テキストを入力すると一致件数と一致位置を表示する。
- 各一致について、番号付きキャプチャグループと名前付きキャプチャグループを表示する。
- JavaScriptの置換文字列を入力すると置換結果を即時プレビューし、コピーできる。

### ポート疎通テスター

- ホスト名またはIPアドレス、TCPポート、タイムアウトを指定して接続可否を確認できる。
- 成功時は接続先アドレスと接続所要時間を表示し、失敗時はOSから得たエラーを表示する。
- HTTPリクエストやデータ送信は行わず、TCP接続の成立だけを確認する。

### マウス効果（Windows）

- マウス効果は設定画面から有効・無効を切り替える。
- クリック波紋を有効にすると、左右または中央ボタンを押した位置へリングを表示する。
- 表示色、形（円・角丸四角・四角）、表示時間、最大サイズ、線の太さを設定できる。
- 表示設定は波紋監視中でもアプリを再起動せず反映できる。
- オーバーレイは最前面かつクリック透過とし、背後のアプリへの入力を妨げない。
- マウス入力はフックせず、位置とボタン状態を読み取るポーリング方式とする。
- 有効状態と表示設定をSQLiteへ保存し、Local Hubの次回起動時に自動的に復元する。

## 文書の更新方針

- 利用者から見える仕様や実装契約を変更した場合は、この文書を更新する。
- 実装・修正の履歴は`CHANGELOG.md`へ日付付きで追記する。
- アーキテクチャ上の重要な選択を行った場合は、該当するADRを追加または更新する。
