# Local Hub 仕様

この文書は、利用者から見える動作と実装が満たすべき契約を記録する。
システム構成の現状は`ARCHITECTURE.md`、設計判断と背景は`adr/`、変更単位の履歴は
`CHANGELOG.md`を参照する。

## プラグイン

### 実行と通信

- プラグインのサイドカー実行ファイルはLocal Hubの子プロセスとして起動する。
- コアとサイドカーは、標準入力・標準出力上の改行区切りJSON-RPCで通信する。
- 標準エラー出力はコアが収集し、プラグインログとして表示する。
- Windowsでは、コンソール型サイドカーであっても独立したコンソールウィンドウを
  表示しない。ウィンドウを表示しない場合も、標準入出力のパイプは維持する。
- サイドカーの終了はコアが監視し、意図しない終了はクラッシュとして扱う。

### 障害分離

- プラグインはコアプロセスから分離し、プラグインの障害でLocal Hub本体を終了させない。
- 短時間の連続クラッシュを検出したプラグインは自動的に無効化する。

## グローバルショートカット

- ウィンドウの表示・非表示を切り替えるグローバルショートカットを設定できる。
- キー割り当ては文字列を手入力せず、設定欄にフォーカスして実際のキーの組み合わせを
  押すことで指定する。
- 修飾キーを押すと記録中の組み合わせを表示するが、修飾キーだけでは割り当てを確定しない。
  記録中に`Esc`を単独で押すと変更を取り消す。
- 検出した割り当ては「適用」を押した時点で登録・保存する。登録できない組み合わせや
  他アプリと競合する組み合わせはエラーを表示する。

## 文書の更新方針

- 利用者から見える仕様や実装契約を変更した場合は、この文書を更新する。
- 実装・修正の履歴は`CHANGELOG.md`へ日付付きで追記する。
- アーキテクチャ上の重要な選択を行った場合は、該当するADRを追加または更新する。
