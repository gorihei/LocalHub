# ADR-0008: SQLをフロントエンド内で整形する

## ステータス

決定・実装済み(2026-09-05)

## 経緯

開発者ツールへSQLフォーマッターを追加する。SQLにはデータベース製品ごとの差異があり、
単純な文字列置換による独自実装では、コメント、文字列リテラル、予約語、方言固有の構文を
安全に扱いにくい。また、入力されたSQLを外部サービスへ送らないという開発者ツールの
ローカル処理契約を維持する必要がある。

## 決定

フロントエンド依存関係として`sql-formatter`を採用し、WebView内でSQLを整形する。
標準SQLと主要なデータベース方言を選択でき、キーワードの文字種とインデント幅も指定できる。
エディタと構文装飾にはCodeMirror 6、React統合には`@uiw/react-codemirror`を使用する。
一貫した編集操作を提供するため、この共通エディタを開発者ツール内のすべての複数行
入力・出力へ適用する。対応する言語パーサーがある場合は構文を色分けし、それ以外は
プレーンテキストとして扱う。初期表示への影響を抑えるため、開発者ツール画面は遅延ロードする。
ネットワークAPIは使用しない。

## 影響

- 入力されたSQLは端末外へ送信されない。
- `sql-formatter`、CodeMirrorとその推移的依存関係がフロントエンドの配布サイズへ加わる。
- ライブラリ更新時は各方言の代表的なSQLで整形結果を再検証する必要がある。

## 見送った代替案

- 外部整形API: SQLに含まれ得るテーブル名や条件値を外部送信するため不採用。
- 独自フォーマッター: 方言対応と字句解析の保守コストが高いため不採用。
