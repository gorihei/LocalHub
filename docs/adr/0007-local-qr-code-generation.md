# ADR-0007: QRコードをフロントエンド内で生成する

## ステータス

決定・実装済み(2026-09-05)

## 経緯

開発者ツールへQRコードジェネレーターを追加する。Local Hubの開発者ツールは、入力を
暗黙に外部送信せずローカルで処理することを基本契約としている。外部のQRコード生成APIは
実装が簡単な一方、URLや接続情報などが第三者へ送信されるため、この契約に適合しない。

QRコードの符号化処理を独自実装すると、規格対応や誤り訂正の検証コストが高くなる。

## 決定

フロントエンド依存関係として`qrcode`を採用し、WebView内でQRコードを生成する。
ネットワークAPIは使用しない。生成したData URLはプレビューに用い、PNG保存時に
バイト列へ変換して既存のTauriファイル書き込みプラグインへ渡す。

## 影響

- QRコード生成時に入力内容は端末外へ送信されない。
- `qrcode`とTypeScript型定義`@types/qrcode`が依存関係に追加される。
- QRコード処理分だけフロントエンドの配布サイズが増える。
- ライブラリ更新時は生成結果とPNG保存を再検証する必要がある。

## 見送った代替案

- 外部生成API: 入力内容を外部送信するため不採用。
- QRコード規格の独自実装: 保守・検証コストと実装不良のリスクが高いため不採用。
