# ADR-0005: ダッシュボードのタブによるウィジェットグループ化

## 状態

採用（2026-08-22）

## 背景

ダッシュボードへ配置できるウィジェットが増え、単一の縦長グリッドでは目的の情報を
確認するためにスクロールが必要になった。ウィジェットの追加・削除・サイズ変更という
既存操作を維持しながら、用途ごとに表示範囲を分ける必要がある。

## 決定

- ダッシュボードは、名前を持つ複数タブとタブごとの`react-grid-layout`レイアウトで構成する。
- ウィジェットは全タブを通じて一つのタブだけに所属し、編集モードから別タブへ移動できる。
- タブの追加・名称変更・削除を編集モードで提供する。
- 新形式は`app_settings.dashboardTabs`へJSONとして保存する。
- 旧`dashboardLayout`しか存在しない場合は、その内容を「メイン」タブへ自動移行する。
- プラグインのアンインストール時は、旧形式と新形式の両方から対象ウィジェットを除去する。

## 結果

通常表示ではタブ切り替えだけが追加され、既存のグリッド操作は変わらない。タブごとに
表示するウィジェット数を抑えられるため、スクロール量を減らせる。一方、永続化形式と
プラグイン削除時のクリーンアップは複数タブを考慮する必要がある。
