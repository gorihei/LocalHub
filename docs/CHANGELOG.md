# 変更履歴

Local Hubの実装変更を日付単位で記録する。新しい変更を上に追記する。

## 2026-09-05

### 変更

- 利用頻度の低い自動化メニューをサイドバーから削除した。既存の保存データと
  バックエンド処理は互換性維持のため保持する。
- ウィンドウの表示・非表示を切り替えるグローバルショートカットを、文字列の手入力ではなく
  実際に押したキーの組み合わせから自動判定する方式へ変更した。
- 記録中に`Ctrl`、`Alt`、`Shift`、Windowsキーを押した時点で、入力欄へ途中の
  キー組み合わせを表示するようにした。

### 追加

- 開発者ツールに、SQL方言、キーワードの大文字・小文字、インデント幅を選択できる
  ローカルSQLフォーマッターを追加した。入力と整形結果はSQL構文を色分けして表示する。
- 開発者ツールに、誤り訂正レベルと画像サイズを選択してPNG保存できる
  ローカルQRコードジェネレーターを追加した。
- 開発者ツールに、指定ホスト・TCPポートの接続可否と応答時間を確認できる
  ポート疎通テスターを追加した。
- Windows全体で使用できるクリック波紋を追加した。

### 改善

- 開発者ツール内の複数行エディタをCodeMirrorへ統一し、JSON、YAML、XML、Markdown、
  SQLの構文装飾と、その他のテキストツールで共通の編集操作を利用できるようにした。
  エディタ依存関係は開発者ツールを開いたときだけ遅延ロードする。
- 開発者ツールボックスのメニューを独立したスクロール領域にし、項目が増えても
  選択中のツール表示を押し下げないようにした。
- 肥大化していたホーム、開発者ツール、設定画面を機能単位のコンポーネントへ分割した。
  画面本体はナビゲーションと状態の統合に責務を絞り、ダッシュボード定義、ウィジェット描画、
  開発者ツールのカテゴリ、設定パネルをそれぞれ専用ディレクトリで管理する構成へ変更した。
- 正規表現テストに置換結果のプレビュー、番号付きキャプチャグループ、名前付き
  キャプチャグループの表示を追加した。
- クリック波紋の切り替えを開発者ツールから設定画面へ移し、有効状態の保存と
  Local Hub起動時の自動復元に対応した。
- クリック波紋の色、形、表示速度、最大サイズ、線の太さをカスタマイズし、設定を
  次回起動時に復元できるようにした。

### 修正

- 開発者ツールのコードエディタでTabキーを押した際、行頭ではなく現在の
  選択範囲またはカーソル位置へタブ文字を挿入するよう修正した。
- マウス効果用の全画面Tauri WebViewがメイン画面の操作や描画へ干渉する問題を修正した。
  追加WebViewを廃止し、Reactやウィンドウ状態管理から独立したWin32のクリック透過
  レイヤードウィンドウへ置き換えた。
- Windowsのインストール版でコンソール型プラグインを起動すると、別のコンソール
  ウィンドウが表示される問題を修正した。
- 表示されたコンソールウィンドウを閉じると、プラグインプロセスも終了して
  クラッシュ扱いになる問題を解消した。

### 文書

- 利用者から見える動作と実装契約を記録する`SPECIFICATIONS.md`を追加した。
- ADRとは別に、日々の修正内容を記録する本変更履歴を追加した。
